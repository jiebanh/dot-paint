# dot tool for web and vscode

dot art tool for web and vscode

## core feature

- can create dot art
- variable size
  - at most 512 * 512
- using color palette
  - can change colors
    - when color changed, corresponding dot will be repainted
  - has transparent color
- uisng color themes
  - a theme consists of many colors
  - when themes changed, dots will be repainted
- png output
- brushes
  - circle and square
  - adjustable size
- works on web and vscode
