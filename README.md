# dot-paint

ブラウザ (VSCode 内蔵ブラウザを含む) 上で動作するドット絵作成ツールです。
ビルド不要の静的な HTML/CSS/JS のみで構成されているので、`index.html` を
ブラウザで開くだけで利用できます。

## 使い方

- キャンバス上のドットをクリックすると、選択中のパレット色でそのドットが塗られます。
- パレットのスウォッチをクリックすると、描画色として選択されます。
- パレットのスウォッチ下のカラーピッカーで色を変更すると、その色番号を使っている
  すべてのドットの色が即座に一括で変わります (ドットは色そのものではなく、
  パレットの色番号を保持しているため)。
- 「+ Add color」でパレットに新しい色を追加できます。

## 開発

コアのデータモデル (`src/paintModel.js`) は DOM に依存しないため、Node.js の
組み込みテストランナーで単体テストできます。

```sh
npm test
```
